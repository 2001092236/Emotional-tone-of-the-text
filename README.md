# Корпус публичных высказываний · 2026

Русскоязычный независимый исследовательский проект для анализа открытых публикаций **Дональда Трампа, Владимира Путина и Владимира Зеленского**. Не является официальным ресурсом МГИМО или органов власти. Данные — **только с 1 января по 7 ноября 2026 года**, без постоянного мониторинга и расписания. Исходные тексты сохраняют исходные языки; сайт и описания на русском.

## Лицензии и научная публикация

**Проект некоммерческий, но его GitHub-репозиторий публичен.** Собственный программный код — [PolyForm Noncommercial 1.0.0](LICENSE), авторские научные материалы и разработанный интерфейс — [CC BY-NC 4.0](LICENSE). **Сторонние речи и посты не перелицензируются**: см. [DATA_RIGHTS.md](DATA_RIGHTS.md) и [веб-страницу о правах](docs/rights.html).

Для неизменённых исследовательских копий официальных речей Зеленского в рамках 2026 года создан отдельный однократный процесс [«Некоммерческая публикация неизменённых речей 2026»](.github/workflows/hf-public-licensed-speeches.yml). Он сохраняет строки `full_text` из архивного Parquet без редакторских изменений, каждую снабжает ссылкой на официальный оригинал, источником HF, SHA-256 и исходной CC BY-NC-ND 4.0. Совпадение вторичной копии с официальным сайтом независимо не проверено. Копии речей хранятся **отдельно** от постов Telegram и Truth Social.

### Альтернативный хостинг вместо GitHub Pages

Подготовлен разовый [GitHub Action «Публикация сайта на Hugging Face Spaces»](.github/workflows/hf-static-site.yml): статический HTML/CSS/JS из `docs/`, без GPU и постоянно работающего сервера. При первом развёртывании Space **приватный по умолчанию** (`HF_SPACE_VISIBILITY=private`). Данные ключа не хранятся в коде.

Для подключения один раз создай в репозитории GitHub **Actions secret** `HF_TOKEN` (fine-grained токен HF с правом записи в Space) и **Actions variable** `HF_SPACE_ID` в формате `username/space-name`. Затем в Actions вручную запусти `Публикация сайта на Hugging Face Spaces`. Для публичного Space задай переменную `HF_SPACE_VISIBILITY=public`. Не отправляй HF-токен в чат, коммиты или Google Документы.

## Отдельно: официальные речи Зеленского

В источнике [slava-medvedev/zelensky-speeches на Hugging Face](https://huggingface.co/datasets/slava-medvedev/zelensky-speeches) обнаружены тексты президентских выступлений с датами, ссылками, языком и содержанием. **Это отдельный вид корпуса, не Telegram-посты**. Пилот `.github/workflows/hf-official-speeches-2026.yml` читает Parquet, оставляет только 2026 год, дедуплицирует речи и рассчитывает модель украинских оригиналов. Выходы: `docs/data/hf_speeches_2026.json`, `docs/data/hf_speeches_index.json`, `docs/data/hf_official_topics.json` и `data/2026/hf_zelensky_speeches_index.jsonl`. На сайте — [`docs/official-speeches.html`](docs/official-speeches.html).

**Права:** метка карточки датасета говорит CC BY 4.0, но `LICENSE.md` и исходный сайт используют **CC BY-NC-ND 4.0**. Мы принимаем более строгий режим: полные тексты обрабатываются только в памяти исследовательского GitHub-runner, но **не попадают в публичный GitHub** и не отправляются в сторонние LLM. Публикуются лишь метаданные, ссылки, хеши и нецитатные статистические темы. Подробности: [лицензирование и источник](research/официальные_речи_HF_2026.md).

Для Путина лицензия материалов `kremlin.ru` — **CC BY 4.0 при ссылке на оригинал**, однако на GitHub runner автоматическая загрузка из Кремля завершается тайм-аутом, а президентский сайт Украины возвращает HTTP 403. Отсутствующие полные стенограммы нельзя подменять пресс-релизами. Академический корпус GWU содержит 2024, а не 2026 год. [Протокол источников](research/официальные_источники_2026.md).

## Аналитика и интерфейс

- `docs/index.html` — светлый русскоязычный сайт: период, лидер, источник, недельная активность, реестр документов, фильтры по тексту, жанру и атрибуции.
- `docs/official-speeches.html` — отдельная страница официальных речей Зеленского, доступные даты и темы, ссылки на оригиналы (без публикации их полных текстов).
- `docs/itar.html` — научный ITAR-пилот с динамикой накопления тем, устойчивостью разных инициализаций и NPMI по источникам.
- `docs/audit.html` — аудит ошибок и календарных пробелов, статус технического доступа к официальным архивам.
- `docs/method.html` — методы, зарубежные аналоги, лицензии и ограничения.
- `docs/data/topics.json` — прежняя регуляризованная PLSA по текущим источникам, отдельно от NMF.
- `docs/lexical-shift.js` — лексический сдвиг между половинами периода (Monroe–Colaresi–Quinn, 2008).

В работах [Воронцова и соавторов](research/тематические_модели.md) важны аддитивные регуляризаторы и устойчивость набора тем. Эксперимент `corpus2026/itar.py` использует фиксацию и фильтрацию по мотивам [Горбулева, Алексеева и Воронцова (2024)](https://arxiv.org/pdf/2408.05840); реализована **часть ITAR**, а не исходный код авторов. Проверка устойчивости и обоснование ограничений — в [научном протоколе](research/ITAR_эксперимент_2026.md). Не следует приписывать полученные темы личному мировоззрению политика без экспертной валидации.

## Разовый запуск без GPU

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m corpus2026.audit --until 2026-11-07 --out docs/data/audit.json
python -m corpus2026.cli build-site
```

Для полного аналитического пилота:

```bash
python -m pip install -r requirements-analysis.txt 'pytest>=8,<10'
python -m corpus2026.topic_model --data-dir data/2026 --out docs/data/topics.json --max-docs 1400
python -m corpus2026.itar --data-dir data/2026 --out docs/data/itar_experiment.json
```

GitHub Actions настроен на отдельные **разовые** запуски: сбор, импорт речей HF, PLSA и ITAR. Нет ежедневных задач, GPU-сервера и передачи ключей в репозиторий. `groundkit` рассматривается лишь как отдельный будущий слой проверки предлагаемых названий тем без отправки корпуса в открытые модели.

## Принципы воспроизводимости

1. Полный годовой архив пока **не подтверждён** независимым контрольным списком. Количества разных жанров нельзя сравнивать как частоту личных высказываний.
2. Сохраняем исходные даты, первичные ссылки, языки, источниковую атрибуцию и SHA-256 модели/датасета. Не используем 2025 год.
3. Тематические модели — гипотезы для исследования, не доказательства психологических качеств, намерений или политической позиции.
4. Не нарушаем robots.txt, не обходим CAPTCHA и не используем зеркала, запрещающие автоматизированный доступ, без разрешения.
