Методика, ограничения и аналоги

Сайт предназначен для воспроизводимого анализа открытых текстов за 2026 год. Данные разделены по источнику, жанру и степени атрибуции. Публичный пост, стенограмма и пересказ пресс-службы — разные объекты; их нельзя автоматически объединять в один «речевой профиль».

1. Что именно собрано

Трамп. Вторичный архив постов Truth Social, полученный из CNN. Путин. Публичные сообщения Telegram пресс-службы Кремля, не личные высказывания. Зеленский. Публичные сообщения Telegram, авторство конкретного поста не проверено. Полные стенограммы Кремля и официальные обращения украинского президентского сайта не вошли в первую выгрузку из-за ограничений доступа.

Отчёт о запуске, даты получения и ошибки: data/2026/run_report.json. Отсутствие документа в архиве не означает, что политик в этот день ничего не публиковал.

Первое наблюдение корпуса: 1 января — 7 ноября 2026 года. 2025 год исключён. Период изменения вручную на графиках не переобучает тематическую модель — он пересчитывает описательные показатели и фильтрует записи.

2. Модели и методы

Базовая модель. NMF с TF–IDF: интерпретируемая контрольная точка, с которой сравниваются регуляризованные тематические модели.

Исследовательская модель. Экспериментальная PLSA с аддитивной регуляризацией разреженности распределений и декорреляции тем — частная реализация идей Воронцова и Потапенко. Она не идентична BigARTM и не реализует ITAR. Оба метода обучаются на отдельных корпусах английского, русского и украинского языков; результат хранит вектор вероятностей тем по документам.

Качество. NPMI по совместной встречаемости ключевых слов в документах, разнообразие слов, стабильность по случайным и временным подвыборкам (последний показатель — в плане валидации), а также экспертная оценка связности. Высокая автоматическая когерентность не доказывает точности политической интерпретации.

Расширение. Полноценный BigARTM (фоновые темы, разреженность, декорреляция, баланс тем), а затем ITAR для итеративного сохранения найденных качественных тем. Для корпуса с разным объёмом источников особенно важен подход Веселовой и Воронцова к балансировке тем. Нельзя просто объединять 5000 постов Трампа с 1000 пресс-релизов Кремля и интерпретировать общую матрицу как сопоставимую шкалу.

Для подтверждения научных выводов предусмотрены: ручная разметка не менее 15–25 тем, сравнение с контрольной NMF, сравнение нескольких инициализаций, отдельная проверка фоновых слов и независимый тест документов. Только после этого можно формулировать выводы о тематической динамике.

3. Бесплатные LLM и вычисления

groundkit уже поддерживает резервное переключение провайдеров и проверку ссылок. В этой системе его стоит подключать как опциональный постпроцессор: предложить человеку название для найденной темы, подготовить краткое описание и проверить ссылку на документ. Модель не должна выдумывать политическую классификацию или цитату.

Где считать: CPU в GitHub Actions достаточен для пилотной PLSA / NMF, GPU не нужен. Для последующих эмбеддингов или больших моделей можно отдельно использовать Hugging Face Spaces, Kaggle либо Colab. Сырые тексты не передаются бесплатным API без оценки условий обработки и отдельного согласования.

5. Принципы визуального интерфейса

  • Светлая научная палитра: белый, серо-зелёный и приглушённый синий. Цвет кодирует источники и лидеров, а не оценку политики.
  • Визуальное доказательство: каждая цифра связана с исходными JSON, у каждого документа — URL и класс атрибуции.
  • Только три важных фильтра: политик, интервал, источник. Поиск по текстам находится в отдельном разделе, чтобы не перегружать главный экран.
  • Никакой фальшивой институциональной айдентики: собственная геометрическая эмблема, без гербов и логотипа МГИМО, без сгенерированных фотографий лидеров.
  • Интерактивность по делу: кликабельные недели, архивные первоисточники, матрица «лидер × канал × тип», темы с ключевыми словами и документами-примерами.

Трёхмерные декоративные диаграммы не используются: они искажают считывание величин. Многомерность представлена согласованными фильтрами и таблицей срезов.
