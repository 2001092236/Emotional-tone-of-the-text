# Полные речи Зеленского: независимый датасет и лицензия (2026)

Дата проверки: 8 ноября 2026. Источник: [Hugging Face — slava-medvedev/zelensky-speeches](https://huggingface.co/datasets/slava-medvedev/zelensky-speeches). Файлы и метаданные имеют столбцы `date` (Unix seconds), `link` (URL исходной речи), `topic` (заголовок), `full_text` (оригинальный текст) и `lang` (`uk`/`en`). Указано порядка 3,7 тыс. записей из разных лет; **это не число речей за 2026 год**. Последняя дата публикации в исследовательской копии должна быть установлена запуском, а не догадкой по дате файлов.

## Права

- В метаданных датасета Hugging Face указана метка `cc-by-4.0`, но файл `LICENSE.md` содержит **Creative Commons Attribution-NonCommercial-NoDerivatives 4.0**.
- [Исходный сайт президента Украины](https://www.president.gov.ua/en/subscribe/) также указывает CC BY-NC-ND 4.0. **Принимаем более строгую лицензию** до выяснения противоречий у владельца набора; модель не получает права объявлять чужие тексты CC BY 4.0.
- Прямая политическая речь в официальном источнике может быть подготовленным документом, а не спонтанным устным высказыванием. Английские переводы не годятся для украинской стилометрии.
- При историческом импорте в публичный GitHub **НЕ сохраняется `full_text`**; публикуются только первичные ссылки, даты, языки, число слов, SHA-256 и экспериментальные статистические темы. Полный текст живёт только в памяти GitHub runner во время однократного расчёта, без сети к LLM. Результаты не предназначены для коммерческого использования.

## Компоненты

- `corpus2026/import_hf_zelensky.py` — загрузка открытого Parquet (лимит размера 35 MB), проверка origin и даты, дедупликация `(original URL, language)`, расчёт источниковой модели на украинских речах отдельно от Telegram.
- `data/2026/hf_zelensky_speeches_index.jsonl` — публичные метаданные, **без текста**.
- `docs/data/hf_speeches_index.json` — те же метаданные для интерфейса.
- `docs/data/hf_speeches_2026.json` — фактическое количество, месяцы, период и статусы лицензии.
- `docs/data/hf_official_topics.json` — отдельная модель украинских речей, экспериментальная и необученная вручную.
- `docs/official-speeches.html` — отдельная русскоязычная веб-страница результатов.

Никакие публикации за 2025 год и ранее не переносятся. Никаких CRON, постоянного сервера, GPU и приватных API ключей не требуется. Обнаруженные пропуски **не являются** отсутствием выступлений.

## Дополнительные источники для России

- [Kremlin.ru](https://kremlin.ru/about/copyrights) открыто разрешает републикацию материалов при ссылке на оригинал (Creative Commons Attribution 4.0), за исключением ряда сторонних фотографий. Машинная доступность из GitHub Actions всё равно ограничена тайм-аутами.
- [Russia Program GWU — Vladimir Putin’s public speeches](https://therussiaprogram.org/data-tools/putins_public_speeches) — качественно размеченный по говорящему, предложениям и датам корпус, но **только за 2024 год**: не добавлять его к выборке 2026.
- [Harvard Dataverse — Linked Multi-Modal Data on Russian Domestic and Foreign Policy Speeches](https://doi.org/10.7910/DVN/SGI0VK) — академический архив речей за предыдущие десятилетия; доступное описание **не удостоверяет покрытие 2026 года**. Проверить CSV метаданные прежде чем включать в строгий 2026 корпус.

Принцип: для личного речевого профиля выделять реплики `speaker = Путин`, отделять комментарии пресс-службы, оставлять оригинальный русский текст и URL. Дубли Telegram и официальных стенограмм одного мероприятия объединять по `event_id`, а не суммировать как независимые выступления.
