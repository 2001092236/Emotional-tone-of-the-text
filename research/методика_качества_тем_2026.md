# Научная методика проверки тем — политические тексты 2026

Статус: исследовательская ветка. Нельзя объявлять найденной лучшую модель без всех экспериментальных запусков и независимой проверки.

## Основные ошибки предыдущей версии

В main используется CountVectorizer без лемматизации. Поэтому «Россия/России/Россией», «Україна/України/Україні», «США/Соединённые Штаты» распадаются на разные признаки. Словари переполнены глаголами-штампами, жанровыми словосочетаниями и дублями. Старый пуск имеет фиксированные K=7, seed=42 и 30 итераций без систематического перебора. Это ARTM-inspired pLSA, а не официальный BigARTM, а локальная программа ITAR использует дополнительную жёсткую фиксацию, которой не гарантирует исходная статья. Названия «Тема 1» — не научная интерпретация.

Новая ветка: обязательные spaCy-модели ru_core_news_sm, uk_core_news_sm, en_core_web_sm; канонизация названий США, ЕС, НАТО и СВО без смешивания разных политических фреймов; статистическое обнаружение устойчивых словосочетаний Phrases; объединение похожих кластеров; межтемные сравнения; 3–5 документов-свидетельств из разных месяцев; не публикуемые без доказательной оценки названия.

## Реально сравниваемые семейства

Вероятностные: LDA, официальный C++ BigARTM с разреживающими и декоррелирующими регуляризаторами, ITAR-inspired как пилот (НЕ реплика исходного кода), BTM для коротких Telegram/X. Контрольные факторизации: NMF и SVD+k-means. Контекстные: BERTopic + HDBSCAN; embeddings + k-means/c-TF-IDF; CombinedTM (контекст+BoW); Top2Vec. Не считать два набора гиперпараметров одной модели двумя разными алгоритмами.

3 HF модели с GPU:
- Qwen/Qwen3-Embedding-0.6B https://huggingface.co/Qwen/Qwen3-Embedding-0.6B
- BAAI/bge-m3 https://huggingface.co/BAAI/bge-m3
- intfloat/multilingual-e5-large-instruct https://huggingface.co/intfloat/multilingual-e5-large-instruct

Обновлённая сетка на каждого лидера: NMF 4 K × 3 коэффициента (12); LDA 4 K × 2 prior (8); ARTM-lite 4 K × 2 силы регуляризации (8); SVD+k-means 4 K; TF-IDF+k-means 4 K; иерархическая кластеризация на SVD 4 K. Вместе 40 параметризованных CPU-конфигураций плюс BigARTM, BTM и ITAR = **43 попытки на каждого лидера**. Для BigARTM доступен официальный wheel 0.9.2 под CPython 3.11 Linux (https://pypi.org/project/bigartm/), он включён в воспроизводимый workflow; успешность проверяется реальным запуском. С GPU ещё 24 сочетания: каждый из 3 энкодеров × (3 k-means + 2 BERTopic/HDBSCAN + 2 CombinedTM + 1 Top2Vec).

## Оценка качества

Начиная с второго CPU-прогона обязательно считать долю документов с ненулевым тематическим распределением (**document_coverage**), эффективное число тем (энтропийная сбалансированность) и максимум доли крупнейшей темы. Проверка исключает модели с coverage ниже 90%, менее 55% сохранившихся тем, менее четырёх тем либо крупнейшей темой свыше 45% корпуса. Полученный агрегированный score — инженерный эвристический показатель, **не научно установленная единая метрика**. Он не заменяет Pareto-анализ и семантический аудит.

Каждая модель получает средний NPMI топ-10 терминов; topic diversity@10; долю пар повторяющихся тем по пересечению признаков; число непредставленных и малых тем; покрытие документов; семантическую оценку локальной LLM и, после реализации, устойчивость по seed/бутстрепу и качество на отложенных временных отрезках. Когерентность — не единственная целевая функция. Не сравнивать абсолютный NPMI между разными языками как равноценную величину.

Пример плохих тем: «Встречи президента с чиновниками» и «Заседания президента с министрами» в большом объёме пресс-службы могут быть жанровыми категориями, а не политическими сюжетами. «Америка/Соединённые Штаты/США» — одна сущность. «Україна/України/Україні» — одна лемма. «Great/thanks/wonderful» — риторическая форма, не тема. «Военные удары», «ПВО и защита городов», «Переговоры о прекращении войны» могут быть разными, только если документы это подтверждают.

Локальный GPU LLM Qwen/Qwen3-8B оценивает тему, видя топ-слова и доказательные документы с датами/ID: (1) смысловая цельность; (2) доказательность названия; (3) отличие от соседних тем; (4) политическая содержательность, каждое 0–5. Название на русском, 3–9 слов, подтверждено хотя бы двумя исходными документами. Требовать не менее 4/5 по всем четырём критериям и не менее 85% хороших тем. Не навязывать красивое название статистически несвязному кластеру. Это LLM-проверка, НЕ независимая экспертная валидация; последняя обязательна для научного релиза.

Не менять отдельные веса нейронной сети субъективно: это уничтожает воспроизводимость. Если действительно нужна адаптация, делать контрастивный fine-tuning или LoRA на размеченных парах «один сюжет / разные сюжеты» с hard negatives, отдельными train/validation/test и зафиксированными версиями; сравнивать по слепой независимой оценке.

## Запуск

CPU-срез: установить requirements-analysis.txt и spaCy 3.8, gensim, bitermplus; затем скачать en_core_news_sm, ru_core_news_sm, uk_core_news_sm. Запустить команду python -m corpus2026.topic_lab --mode cpu --max-docs 900. Этот отчёт НЕ может пройти GPU-гейт.

Полный режим на GPU: установить torch CUDA, transformers, sentence-transformers, bertopic, umap-learn, hdbscan, contextualized-topic-models, top2vec и три spaCy-пакета; отдельно собрать BigARTM C++ + Python binding совместимой версии. Запустить python -m corpus2026.topic_lab --mode full --max-docs 1400. Для LLM-сопоставления локально развернуть совместимый с Chat Completions vLLM по адресу http://127.0.0.1:8000/v1 и запустить python -m corpus2026.topic_review. Никакие исходные тексты не отправлять во внешнюю LLM без отдельного правового решения.

Публикация запрещена, пока для каждого лидера не завершены минимум 20 комбинаций, 7 реально разных методов, 3 GPU-энкодера, устойчивость и отложенная проверка, лингвистический аудит и валидные документальные русскоязычные имена. Актуальная метрика принятия в коде частичная и требует расширения на bootstrap stability и holdout до индустриального релиза.

## Атрибуция

Truth Social Трампа — вторичный архив, полнота не доказана. Канал Кремля — пресс-служба, не личные стенограммы Путина. Telegram Зеленского — публикуемый канал, нельзя автоматически приписывать каждый пост лично Зеленскому. Официальные украинские речи представляют самостоятельный жанр и пока не смешиваются с Telegram. По иностранным лидерам нельзя делать клинические или окончательные психологические выводы из политических материалов.
