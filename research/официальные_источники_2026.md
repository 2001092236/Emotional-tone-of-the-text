# Доступ к официальным речам за 2026 год — технический и правовой протокол

Период исследования: 01.01.2026–07.11.2026. Проверка доступа выполнена GitHub Actions 08.11.2026.

- Украинский президентский архив на `president.gov.ua`: HTTP 403 при запросе `robots.txt` из GitHub Actions. Следовательно, массовый автоматический сбор в этом окружении не запускается, даже если веб-страницы иногда доступны в браузере или поисковой выдаче.
- Официальные домены Кремля `kremlin.ru`, `news.kremlin.ru`, `en.kremlin.ru`: тайм-аут при запросе `robots.txt` из GitHub Actions. Это техническая недоступность, а не основание обходить защиту.
- Платформа PublicNow публикует зеркальные копии материалов, но [условия Public Technologies](https://www.publicnow.com/terms-and-conditions/) (разделы 2.8 и 2.9) запрещают автоматизированное использование/архивирование/зеркалирование и ограничивают ссылки на материалы без письменного согласия. Поэтому этот источник **исключён из автоматизированных проверок и коллектора**. При необходимости полного корпуса следует запросить лицензированный доступ.
- Публичные материалы Telegram и CNN Truth Social остаются отдельными типами источников. Тексты пресс-службы Кремля не считаются личными высказываниями Владимира Путина; официальные английские переводы не равнозначны украинскому/русскому оригиналу.

## Следующие разрешённые варианты

1. Обратиться к пресс-службам для официальной выгрузки полного набора стенограмм или RSS/API с разрешением на исследовательское использование.
2. Импортировать предоставленный исследователю архив HTML/JSON/CSV при проверке его происхождения, дат и разрешений; сохранять первичный идентификатор публикации и контрольную сумму.
3. Для текущей системы использовать уже доступные открытые каналы с явно указанными ограничениями и проверкой календарной полноты (`data/2026/audit_report.json`).

**Важно:** мы не считаем закрытые от GitHub runner архивы пустыми; отсутствие записей в нашей БД не является политическим фактом.
